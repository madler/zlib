### Security Policy

#### Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, submit a confidential report using GitHub's **Private Vulnerability
Reporting** feature by going to the **Security** tab of this repository and
clicking **Report a vulnerability**.

***Only submit a report if you know what you are doing.***

Include a clear technical description of the issue and a working proof of
concept (PoC). The PoC must use only the documented API and obey its rules. If
you have to go around or violate the API, it is not a vulnerability. Unverified
AI-generated findings or raw automated scanner output will be closed without
response.
